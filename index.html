함께 쓰기 설정

두 사람이 같은 목록을 보려면 Supabase 데이터베이스 연결이 필요해요. 아래 정보를 한 번 입력하면 이 브라우저에 저장됩니다.

처음 한 번만 필요한 설정
1. Supabase에서 새 프로젝트를 만들어요.
2. SQL Editor에 아래 SQL을 실행해요.
3. Project URL과 anon key를 위에 붙여넣고 연결해요.

create table public.food_places (id uuid primary key default gen_random_uuid(), name text not null, category text default '기타', country text default '대한민국', region text, url text, photo text, memo text, recipe text, visited boolean default false, created_at timestamptz default now());
alter table public.food_places add column if not exists country text default '대한민국';
alter table public.food_places add column if not exists region text;
alter table public.food_places add column if not exists recipe text;
alter table public.food_places enable row level security;
create policy "public read" on public.food_places for select to anon using (true);
create policy "public insert" on public.food_places for insert to anon with check (true);
create policy "public update" on public.food_places for update to anon using (true) with check (true);
create policy "public delete" on public.food_places for delete to anon using (true);

※ 이 설정은 링크를 아는 누구나 목록을 보고 수정·삭제할 수 있는 공개형 공유 방식이에요. 민감한 정보는 입력하지 마세요.
